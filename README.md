# Kiel Snowmobile Club

Modern redesign of the [Kiel Snowmobile Club](https://www.kielsnowmobileclub.com/) website — dedicated to safe and responsible snowmobiling in Calumet County, Wisconsin.

## Features

- **8 sections**: Home, Trail Info, Maps, Membership, Links, Officers/Contacts, Safety Classes, Photos
- Embedded Google Map of Calumet County snowmobile trails
- Photo gallery with lightbox viewer and keyboard navigation
- All external links preserved (AWSC, county trails, neighboring clubs, DNR, PayPal, Wufoo forms)
- Responsive design with mobile hamburger menu
- Modern UI with Inter + Bebas Neue fonts, card-based layout

## Local Development

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```

## Deployment

Static site — deploy to GitHub Pages, Netlify, or any static hosting.
